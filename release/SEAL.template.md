ORDER OF ASSEMBLY (the r31 defect, Gate-10 P0-1)

  copied submission/ from the vault and never built inside the distribution. The order is now:
  freeze sources -> assemble the distribution root -> run every package gate ON that root ->
  build the PDF INSIDE that root -> compare build output with the shipping path -> measure ->
  generate TRUST, this seal -> SHA256SUMS -> zip -> re-extract and re-run the shipping gate.
  correspondence/SEAL_r31.txt is retained byte for byte and superseded by this file; its
  invalidation record is history/seals/SEAL_r31_INVALIDATED.md.
